# Landmark Inter Gulf LLC — Official Website

Production-ready Next.js website for Landmark Inter Gulf LLC, a Saudi-based integrated services company providing Manpower Supply, Equipment Rental, Industrial Trading, Petro Services, and Hospitality Services.

## 🚀 Features

- **10 Pages**: Home, About, Projects, Contact + 6 Service pages
- **AI Assistant** (Landmark AI): Powered by Groq Llama 3.3 70B
- **PDF Knowledge Base**: AI answers based on company profile PDF
- **62 AI-Generated Images**: Construction, equipment, refinery, workers
- **25 Client Logos**: Aramco, SABIC, Samsung, SEPCO, and more
- **Hero Slider**: 5-slide auto-advancing carousel
- **Visual Timeline**: Company journey from 2017 to today
- **Glassmorphism Design**: Dark navy + gold industrial theme
- **Comprehensive SEO**: Sitemap, robots.txt, JSON-LD structured data
- **PDF Download**: Company profile download throughout the site

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4 + shadcn/ui
- **Animations**: Framer Motion
- **AI**: Groq (Llama 3.3 70B) via OpenAI-compatible SDK
- **Deployment**: Vercel

## 📦 Installation

```bash
bun install
```

## 🔑 Environment Variables

Create a `.env` file:

```
GROQ_API_KEY=your_groq_api_key_here
```

Get a free Groq API key at: https://console.groq.com/keys

## 🏃 Development

```bash
bun run dev
```

## 🏗️ Build

```bash
bun run build
```

## 🚢 Vercel Deployment

1. Push to GitHub
2. Import project in Vercel
3. Add Environment Variable: `GROQ_API_KEY`
4. Deploy
